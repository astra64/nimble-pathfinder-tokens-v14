# Nimble - Pathfinder Tokens (v14 Fork)

Fork of [javierriveracastro/nimble-pathfinder-tokens](https://github.com/javierriveracastro/nimble-pathfinder-tokens), updated for Foundry VTT v14 and the Nimble system v0.9.0+.

A simple module that maps the tokens from the [Pathfinder Tokens: Bestiaries](https://www.foundryvtt.store/products/pf2e-tokens-bestiaries) module (commercial) to the Nimble System built-in actors.

In simple words, it allows you to use your monster tokens from Paizo with Nimble.

## Requirements

- Foundry VTT v14+
- Nimble system v0.9.0+
- [Pathfinder Tokens: Bestiaries](https://www.foundryvtt.store/products/pf2e-tokens-bestiaries) module

## Changes from upstream

- Module id renamed to `nimble-pathfinder-tokens-v14`.
- Bumped `compatibility` to Foundry v14.
- Bumped required Nimble system version to 0.9.0.
- No changes to the art mapping data — verified against Nimble system v0.9.0's `nimble-monsters` compendium.
